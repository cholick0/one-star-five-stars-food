An alien tourist's one-star review of Earth that still compliments the food, built for [make.fun](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

> One star: the gravity stole my luggage, the locals queue for burnt coffee, yet the rendang alone nearly earns this planet a second one.

`main.ts` writes the single-sentence entry (135 characters) to `/output/entry.txt` and validates it against the gate: 1–200 UTF-8 characters, not blank, exactly one sentence, verified byte-for-byte on read-back.
